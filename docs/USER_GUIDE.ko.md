# AMEVA-Multi-CLI 사용 가이드

## 기본 사용법

### 탭 관리
- **새 탭**: 탭 바 우측 `+` 버튼 클릭
- **탭 전환**: 탭 제목 클릭
- **탭 닫기**: 탭 우측 `×` 버튼 클릭 (마지막 탭 닫아도 새 탭이 자동 생성됨)

### 화면 분할 (패인)
- **패인 추가**: 터미널 영역 오른쪽 끝 `⊞` 버튼 클릭
- **패인 닫기**: 패인 탭 바의 `×` 버튼 클릭
- 패인은 가로로 나란히 배치되며 각각 독립된 쉘 프로세스를 가집니다

### 키보드 단축키
| 단축키 | 동작 |
|--------|------|
| `Ctrl+C` (선택 시) | 선택 텍스트 클립보드 복사 |
| `Ctrl+C` (미선택) | 쉘에 SIGINT 전송 |
| `Ctrl+V` | 클립보드에서 터미널로 붙여넣기 |

## 사이드바

사이드바 토글: 탭 바 왼쪽 `☰` 버튼

### ★ 북마크
자주 사용하는 명령어나 서버 접속 정보를 저장합니다.

- **추가**: `+` 버튼 → 이름과 명령어 입력
- **실행**: 북마크 항목 더블클릭 → 새 패인에서 자동 실행
- **삭제**: 항목 우측 `×` 버튼

예시 북마크 명령어:
```
ssh -p 8022 user@192.168.1.100      # Termux SSH 접속
docker exec -it mycontainer bash    # 컨테이너 진입
kubectl get pods -n production      # k8s 파드 조회
```

### ⟳ 히스토리
실행했던 명령어가 자동 저장됩니다.
- **검색**: 상단 검색창에 키워드 입력
- **재실행**: 항목 클릭 → 현재 활성 패인에서 즉시 실행
- **전체 삭제**: `전체삭제` 버튼

> ⚠️ 비밀번호, API 토큰 등 민감한 정보는 자동으로 `****`로 마스킹되어 저장됩니다.

### ⊞ 워크스페이스
현재 탭·패인 구성을 스냅샷으로 저장하여 나중에 복원합니다.

- **저장**: `저장` 버튼 → 이름 입력
- **복원**: 워크스페이스 더블클릭 (현재 탭은 닫히고 저장된 레이아웃으로 교체)
- **삭제**: 항목 우측 `×` 버튼

## 보안

### 위험 명령 차단
다음 명령들은 자동으로 차단되며 실행되지 않습니다:
- `rm -rf /` (루트 삭제)
- `mkfs.*` (파일시스템 포맷)
- `format C:` (Windows 드라이브 포맷)
- `:(){ :|:& };:` (fork bomb)
- `shutdown now`, `reboot`, `poweroff`

### 민감 정보 마스킹
히스토리에 저장될 때 다음 패턴이 자동 마스킹됩니다:
- `--password VALUE` → `--password ****`
- `token=VALUE`, `api_key=VALUE`
- `Authorization: Bearer TOKEN`
- `GITHUB_TOKEN=VALUE`, `AWS_SECRET_ACCESS_KEY=VALUE`

## Termux (안드로이드) 원격 접속

안드로이드 Termux 앱에 SSH로 접속하는 방법:

1. Termux에서 SSH 서버 실행:
   ```bash
   pkg install openssh
   passwd
   sshd
   ```

2. AMEVA-Multi-CLI에서 북마크 추가:
   - 명령어: `ssh -p 8022 사용자명@안드로이드IP`
   *(Termux 기본 포트는 8022)*

3. 북마크 더블클릭으로 접속
