# AMEVA-Multi-CLI 사용 가이드

## 시작하기
- 앱 실행 후 새 탭 버튼(+)을 눌러 터미널을 열 수 있습니다.
- 화면 분할 아이콘을 눌러 상/하, 좌/우로 패널을 나눌 수 있습니다.

## 북마크 (CLI 객체)
자주 사용하는 접속 정보나 긴 명령어를 저장하여 더블클릭으로 바로 실행할 수 있습니다.
사이드바에서 새 북마크를 생성하세요.

## 워크스페이스
여러 탭과 화면 분할 정보, 그리고 각 패널에서 실행될 북마크를 하나로 묶어 '워크스페이스'로 저장할 수 있습니다.
매일 반복되는 업무 환경을 클릭 한 번에 복원하세요.

## 자동완성과 히스토리
이전에 실행했던 명령어는 자동으로 DB에 저장되며, 터미널에서 입력할 때 추천을 제공합니다.
